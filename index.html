HARDWARE–SOFTWARE CO-DESIGN

TiGPU / FPGA-based 2D graphics acceleration

A RISC-V / FPGA heterogeneous graphics system on an Efinix FPGA platform, combining hardware rendering with a playable game demonstration.

  • Sprite rendering with color-key transparency and alpha blending.
  • DDR burst access, sprite caching, and triple buffering to support the rendering pipeline.
  • Multi-room gameplay, boss encounters, and dense projectile scenes; performance testing across rendering modes.
  • FPGA
  • RISC-V
  • DDR
  • Graphics pipelines
